Swiggy Data Analytics Dashboard

Project Overview
This is an interactive Excel dashboard built to analyze 190,000 rows of food delivery data from Swiggy. It transforms raw transaction records into strategic business insights for performance tracking.

Key Metrics
* Total Transactions: 0.20M orders
* Total Revenue: 53.01 Million Rupees
* Average Product Rating: 4.3 out of 5
* Average Order Value: 268.51 Rupees

Business Insights Uncovered
1. Metropolitan Hubs: Bengaluru leads the nation in top-rated restaurant density with nearly 6,000 elite establishments, followed by Chennai and Ahmedabad.
2. Revenue Bottlenecks: A steep volume drop occurs from January to February down to 23,300 orders, followed by a steady recovery trend starting in March.
3. Pricing Outliers: Isolated multi-million rupee data anomalies to build a precise chart mapping menu price against consumer popularity.

Dashboard Components
* KPIs:
  1) Total orders
  2) Total ratings
  3) Average rating
  4) Gross sales
  5) Average item price

* Visualizations:
  - Monthly volume trend line chart
  - City average price bar chart
  - Restaurant density column chart
  - Price vs popularity scatter plot

* Dynamic Filters:
  - Interactive slicers for quick filtering by geographic States and Cities
  - Timeline tracker for months and quarters

Project Structure
* Swiggy_Raw_Data.xlsx: Primary database with 190k raw records.
* Swiggy_Dashboard.xlsx: Final interactive application page.
